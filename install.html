B钉 v2 · 安装

钉钉 / 飞书 / 企业微信 三合一 B站皮肤 · 单文件 146.0 KB · UTF-8
  1. 浏览器装 Tampermonkey（或 Violentmonkey）。
  2. 点下面的「复制脚本全文」。
  3. 打开 Tampermonkey 面板 →「添加新脚本」，全选删掉模板，粘贴，Ctrl+S 保存。
  4. 打开 bilibili.com，首屏就是 IM 界面；顶栏调色板图标切换钉钉 / 飞书 / 企业微信。
只想先看效果？ 不用装任何东西，打开 preview/harness.html 即可看到三套皮肤的假数据演示（?skin=feishu / ?skin=wecom / ?route=video）。
不要双击 biliding.user.js。 Windows 会用「脚本宿主」打开 .js 并弹 「未结束的字符串常量 / 800A03F7」——那是 wscript 在跑浏览器脚本，属于正常报错，文件本身没坏。 用户脚本只能由浏览器里的油猴执行。
